# AI 내러티브 설계 · 2027학년도 1학기

청운대학교 「디지털스토리텔링」의 2026년 강의자료를 바탕으로 개편한 수업 웹페이지입니다.

**공개 주소:** https://elinahyo.github.io/ai-narrative-design/

## 반영 범위

- 수업 소개, 주차별 학습자료, 실습, 과제 안내, 자료실
- 1–15주차, 총 205장 웹 강의 슬라이드: 개념·예시·실습·프롬프트·산출물
- 주차 카드 클릭 즉시 강의 열기, 이전·다음, 목차·슬라이드 선택, 키보드 이동
- 전체화면 및 지원하지 않는 환경의 확대 보기, 휴대폰 좌우 넘김
- 슬라이드별 주소로 새로고침·공유·뒤로가기 지원
- 주차 검색·필터, 상세 안내, 실습 주차 선택, 프롬프트 예시 복사
- 주차별 실습 기록지 15개 다운로드 (Markdown 텍스트 파일, 메모장 등에서 작성 가능)
- 2026년 참고 원본과 2027년용 Drive 폴더 연결

2027년 적용안이며 확정 강의계획서를 대신하지 않습니다. 제출 기한·제출처·평가 배점·시험 일정은 **준비 중**입니다. 원본 PPT를 수정하거나 Drive 공유 권한을 변경하지 않았습니다. 원본 열람에는 별도 Drive 권한이 필요할 수 있습니다.

자료별 구성 근거와 불일치 처리 방침은 [CURRICULUM.md](./CURRICULUM.md)에 정리했습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 다섯 메뉴와 학기 안내 |
| `styles.css` | 반응형 디자인 |
| `course-data.js` | 주차별 학습 내용과 출처 |
| `lecture-data.js` | 15주차 웹 강의의 개념·예시 슬라이드 |
| `app.js` | 화면 전환·검색·상세 안내·실습 선택·복사 |
| `worksheets/week-01.md` ~ `week-15.md` | 주차별 실습 기록지 |
| `favicon.svg`, `.nojekyll` | 아이콘 및 정적 배포 설정 |

외부 라이브러리·API 키·빌드 과정이 필요하지 않습니다. 웹페이지는 개인정보나 학습 기록을 저장하지 않으며, 과제 업로드·로그인·성적 산출 기능은 없습니다. 기록지는 학생 기기에 내려받아 작성합니다.

## 운영 및 갱신

1. `course-data.js`의 해당 주차 내용·출처를 수정합니다. 개념·예시 슬라이드는 `lecture-data.js`에서 갱신합니다.
2. 수업 내용이나 실습 순서 변경 시 `worksheets/week-XX.md`도 함께 갱신합니다.
3. 확정 일정이나 개정 PPT가 제공되면 관련 화면의 ‘준비 중’과 2026/2027 구분을 함께 갱신합니다.
4. 학생용 자료의 Drive 접근 권한은 별도로 점검합니다. 성적·개인별 설문 응답·연구 수집 데이터는 공개 저장소에 올리지 않습니다.
5. 모바일 메뉴, 주차 카드에서 강의 열기, 슬라이드 이동·목차·전체화면, 검색·필터, 실습 선택·복사, 기록지 링크를 확인합니다.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `/(root)` 설정을 유지합니다. 소스 저장과 Pages 배포 완료는 서로 다른 단계입니다. Actions 배포 결과와 공개 주소에서 각각 확인합니다.

내부 파일은 상대 경로, 메뉴는 `#weeks` 등의 해시 경로를 사용하므로 저장소 하위 주소에서 새로고침해도 작동합니다.

## 웹 강의 사용

주차별 학습자료 → 원하는 주차를 클릭하면 웹 강의가 즉시 열립니다. PPT 첨부·다운로드나 Drive 로그인이 필요하지 않습니다. 왼쪽 목차, 아래 선택 상자, 이전·다음 버튼으로 이동할 수 있습니다. 키보드 좌우 화살표는 이전·다음, Home/End는 처음·마지막 장으로 이동합니다. 모바일에서는 세로로 읽고 좌우로 넘길 수 있습니다.

`#lesson/6/4`는 6주차 4번째 슬라이드입니다. 새로고침해도 같은 슬라이드가 열립니다. 전체화면을 지원하지 않는 환경은 확대 보기로 전환하고, 종료 버튼이나 Esc로 돌아옵니다.

원본 PPT의 모든 장·이미지·애니메이션을 그대로 재생하는 뷰어가 아닙니다. 제공 자료의 개념과 활동을 한국어 HTML 슬라이드로 재구성했으며, 예시는 웹 수업용으로 다시 작성했습니다. 8·14·15주차는 별도 실습·프로젝트 자료를 바탕으로 한 적용안입니다.
