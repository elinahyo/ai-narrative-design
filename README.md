# AI 내러티브 설계

청운대학교 AI 내러티브 설계 수업 웹페이지. 기존 「디지털스토리텔링」을 개편한 교과목의 수업 소개, 주차별 학습자료, 실습, 과제 안내와 자료실을 제공합니다.

**공개 주소:** https://elinahyo.github.io/ai-narrative-design/

## 운영 상태

현재는 수업 공간의 기본 구조를 제공하는 버전입니다. 실제 강의자료, 실습 내용, 과제 기한, 평가 기준, 참고자료와 구글 드라이브 링크는 아직 등록하지 않았습니다. 모든 미등록 항목은 ‘준비 중’으로 표시합니다.

15주차 목록은 자료 입력용 기본 틀이며 확정 강의계획서가 아닙니다.

## 파일 구성

- `index.html`: 다섯 개 메뉴와 수업 안내 화면
- `styles.css`: PC·태블릿·모바일 반응형 디자인
- `course-data.js`: 자료 입력용 주차 목록
- `app.js`: 메뉴 전환, 주차 검색·필터, 주차 안내 대화상자
- `favicon.svg`: 사이트 아이콘
- `.nojekyll`: 별도 빌드 없이 정적 파일 배포

외부 라이브러리, 외부 폰트, 분석 서비스, API 키가 필요하지 않습니다. 개인정보나 학습 기록을 수집·저장하지 않으며 과제 업로드, 로그인, 성적 조회 기능은 없습니다.

## GitHub Pages 배포

Settings → Pages → Deploy from a branch → `main` / `/(root)` 설정을 유지합니다. `main`에 변경 사항이 저장되면 GitHub Pages가 재배포합니다. 저장소에는 코드를 저장하고, 실제 공개 반영 여부는 Pages 배포 작업과 공개 주소에서 따로 확인합니다.

모든 내부 파일 경로는 `./` 상대 경로를 사용하므로 `/ai-narrative-design/` 하위 경로에서 작동합니다. 메뉴는 `#weeks` 등의 해시 주소를 사용해 새로고침과 뒤로가기를 지원합니다.

## 자료 추가 시

1. 제공된 강의계획서를 확인하고 `course-data.js`의 주차 수와 주제를 갱신합니다.
2. 실제 파일·링크 등록 시 해당 화면과 대화상자의 ‘준비 중’ 상태를 함께 갱신합니다. 제목만 변경해도 자동으로 다운로드가 생기는 구조는 아닙니다.
3. 드라이브 링크는 학생용 공유 범위를 확인한 후 등록합니다. 비공개 연구자료·학생 개인별 설문 응답·성적을 저장소에 올리지 않습니다.
4. 모바일에서 메뉴, 검색, 필터, 대화상자 닫기와 가로 넘침을 확인합니다.
